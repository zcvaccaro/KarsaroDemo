# Karsaro Demo

Interactive portfolio demo of the **Karsaro** wellness booking dashboard.
No server, no database — sample data lives in your browser only.

Open the live site (GitHub Pages) or run locally:

```bash
npm install
npm run dev
```

Then visit `#/dashboard`. Use **Reset demo data** in the sidebar anytime.

## What’s interactive

Calendar (current month is always filled), Book Now, Forms customizer, Booking
flow, Services, Locations, Email templates, and more. Other screens explain
what the full product adds.

## Build

```bash
npm run build
npm run preview
```

## Deploy

Pushes to `main` deploy `dist/` to GitHub Pages via `.github/workflows/pages.yml`.
